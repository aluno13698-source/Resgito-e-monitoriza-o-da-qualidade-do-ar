# Registo e Monitorização da Qualidade do Ar (PAP)

Sistema IoT completo baseado em **Arduino Uno WiFi Rev2**, **Node.js / Express** e **Render** para monitorização ambiental em tempo real.

## Personalizar Ícone e Imagem de Fundo no GitHub

Para definir ou trocar o ícone e a imagem de fundo do site diretamente pelo GitHub, basta carregar os ficheiros dentro da pasta **`public/`** com estes nomes:

- **Ícone da App (separador do navegador + logótipo no topo):** `icon.png` (também aceita `.jpg`, `.jpeg`, `.ico`, `.webp`, `.svg`)
- **Imagem de Fundo do Site:** `fundo.jpg` (também aceita `.png`, `.jpeg`, `.webp`)
