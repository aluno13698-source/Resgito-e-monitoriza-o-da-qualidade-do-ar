# Registo e Monitorização da Qualidade do Ar (PAP)

Sistema IoT completo baseado em **Arduino Uno WiFi Rev2**, **Node.js / Express**, **Supabase (PostgreSQL)** e **Render** para monitorização ambiental em tempo real e registo permanente de alertas.

## Base de Dados (Supabase)

Cria a tabela `historico_alertas` no **SQL Editor** do Supabase e adiciona `SUPABASE_URL` e `SUPABASE_KEY` nas variáveis de ambiente do Render.
